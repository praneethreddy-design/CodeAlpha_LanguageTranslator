#To run this project:

1. Get a free Gemini API key from Google AI Studio.
2. Replace YOUR_GEMINI_API_KEY in config.py with your own key.
3. Run:
   py app.py

# 🌍 AI Language Translator

An AI-powered language translator built using Flask and Google's Gemini API.

## Features
- Translate text into multiple languages
- Fast AI-powered translations
- Simple and responsive user interface
- Built with Flask

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API

## Installation

```bash
pip install -r requirements.txt
```

Run the application:

```bash
py app.py
```

Open:

```
http://127.0.0.1:5000
```
